# Mockup Figma — BOOKSPACE (desktop 1440px)

32 artboard SVG, satu file per halaman. Semua dibuat dari kode aplikasi aslinya
(navbar, footer, kartu buku, tabel admin, status pesanan, warna, dan font Inter + Lora).

## Cara pakai di Figma

1. Buka Figma → **New design file**.
2. Seret (drag) semua file `.svg` dari folder ini ke kanvas Figma, atau menu
   **File → Place image** (bisa blok banyak file sekaligus, `Ctrl+A`).
3. Setiap file masuk sebagai **frame** dengan nama halamannya (mis. `01 Beranda`),
   lengkap dengan isi yang bisa diedit: teks, warna, dan posisinya.
4. Kalau font terlihat beda, install/aktifkan **Inter** dan **Lora** dari Google Fonts —
   Figma biasanya menarik keduanya otomatis.
5. Supaya rapi: select semua frame → `Ctrl+Alt+A` (Tidy / auto layout tidak perlu),
   atau pakai **FigJam/Figma → Plugins → "Artboard Organizer"**. Frame sudah berurutan
   sesuai nomor file.

## Lihat semua halaman tanpa Figma

Buka `index.html` di browser — tampil sebagai galeri semua 32 artboard.

## Catatan

- Ukuran artboard: lebar 1440 px, tinggi mengikuti isi (halaman panjang seperti Beranda ± 4100 px).
- Tiap artboard punya strip keterangan di bagian bawah berisi nama halaman dan ukurannya.
- Warna yang dipakai: navy `#0f2255`, oranye `#e05c1a`, krem `#f5f1ea`, teks `#3f4451`.
